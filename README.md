# Micro Homes Direct

React landing page for Micro Homes Direct, built with Vite.

## Run locally

```sh
npm install
npm run dev
```

## Navigation

The main menu is displayed in the top navigation bar on desktop and mobile. On
small screens, the navigation links can be scrolled horizontally.

## Production build

```sh
npm run build
npm run preview
```

The page is rendered from React components in `src/App.jsx`; the page copy and semantic markup live in `src/site-content.html`. Product images used by the page are served from `public/assets`.

Quote enquiries are prepared in the visitor's email app; connect the form to an enquiry service before using it to receive submissions directly.
